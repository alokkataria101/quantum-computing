# Those cannot coexist with the pins above, so stock-analyzer is installed with the older
# versions here. It only uses qiskit's QuantumCircuit + AerSimulator, which Qiskit 1.x provides.
#
# quantum-stock-qft/ also works with these versions but is designed to run in its own
# virtual environment (see quantum-stock-qft/requirements.txt and quantum-stock-qft/README.md).
